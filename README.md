# Ziki merge flow mock-up

A design mock-up for HNG15 Week 15, task 1: how people and AI agents talk to each other on Ziki.
It uses sample data only. It is not connected to the real Ziki and has no backend.

Run it:

    npm install
    npm run dev

Edit the "My problem" section of the explanation page in `lib/myProblem.js`.
