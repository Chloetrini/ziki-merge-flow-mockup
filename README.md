# Ziki fix journey proposal

A design mock-up for HNG15 Week 15, task 1: how people and AI agents work together on Ziki after a fix leaves for GitHub.
It is built on Ziki's real layout, uses sample data only, and is not connected to the real Ziki.

Use the "Current Ziki / With proposal" switch at the top to compare. New parts are marked "Proposed". It starts in light mode; there is a dark mode button in the header.
The write-up is at /proposal. To change the "My problem" section, edit `lib/myProblem.js`.

    npm install
    npm run dev
